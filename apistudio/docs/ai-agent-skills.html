AI Agent Skills

Teach Claude Code, Cursor, Kiro, Copilot, Windsurf, Codex, Gemini and Cline to test, load-test and document your APIs with the openpost CLI.

CLI

Why

When you ask an AI coding agent to "check the API works", it usually writes a throwaway Python or curl script that nobody can rerun. The openpost skill teaches the agent to write API test files instead, run them with the CLI, read failures from the output, and leave behind tests, reports and docs that stay in the repository.

Quick checks with openpost send, saved as tests with --save
Happy path and negative cases per endpoint, secrets kept in environment variables
Load tests with thresholds, HTML and JUnit reports, and docs generated from the tests

Install

npx openpost agent install

Detects which agents the project uses and installs the skill for each

npx openpost agent install --platform claude,cursor,kiro
npx openpost agent install --platform claude --global    # all projects (Claude Code)
npx openpost agent list                                   # platforms and install status
npx openpost agent uninstall --platform cursor

Commit the generated files so everyone on the team, and every agent, gets the same instructions. Running install again updates them in place.

Claude Code Plugin

/plugin marketplace add openAPI-Studio/api-studio

Installs the skill as a Claude Code plugin instead of copying files into the project

Try It

After installing, ask your agent something like:

Test the /tasks endpoints of the API running on localhost:3000.
Cover create, get, list and delete, plus 401 and 404 cases.
Then run a short load test and give me the HTML report.

The agent writes api-tests/tasks.api.yaml, runs openpost validate and openpost test, fixes or reports failures, and tells you the command to rerun and where the report is.
