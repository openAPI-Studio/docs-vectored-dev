Before You Report a Bug

A few problems have known causes and an immediate fix:

  • Captures going to Downloads — folder access has lapsed. Open the popup and press Reconnect.
  • A black recording — the page uses protected video, which the browser excludes from capture.
  • A WebM instead of an MP4 — your Chrome build cannot encode MP4, so Lens named the file for what it actually wrote.
  • The full list is in Troubleshooting.
