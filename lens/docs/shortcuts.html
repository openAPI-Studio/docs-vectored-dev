Keyboard Shortcuts

The default bindings, and how to change them.

Lens registers three commands. Chrome owns the bindings, so they are changed in Chrome rather than in the extension.

CommandmacOSWindows / LinuxWhat it does
Capture region⌘⇧SAlt+Shift+SOpens the region selector
Record GIF region⌘⇧RAlt+Shift+ROpens the region selector ready to record
Capture full tab⌘⇧FAlt+Shift+FCaptures the visible tab with no selection step

1. Changing a shortcut

  1. Open chrome://extensions/shortcuts or follow the link at the top of the Settings page on the dashboard.
  2. Find Lens in the list each command has its own row.
  3. Click the field and press the combination Chrome refuses combinations already taken by the browser or another extension.

Chrome allows a limited number of *suggested* shortcuts per extension, and any command can be left unbound. An unbound command shows as not set on the Settings page; the popup buttons still work.

2. When a shortcut does nothing

  • The tab is a page Chrome does not allow extensions on — chrome:// pages, the Web Store, the PDF viewer. The toolbar icon shows a red ! and its tooltip explains why.
  • Another extension has claimed the same combination. Chrome gives it to whichever registered first; rebind one of them.
  • The page has not finished loading. Wait for it and try again.

See Troubleshooting for the full list of pages capture cannot run on.
