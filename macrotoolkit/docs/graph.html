Graph / Chart

Create interactive charts and graphs using Chart.js. Supports bar, line, pie, doughnut, and area charts with customizable colors and datasets.

Screenshot placeholder

How to Use

  1. Type /Graph in the editor
  2. Select chart type: Bar, Line, Pie, Doughnut, or Area
  3. Enter labels (comma-separated, e.g., Jan, Feb, Mar)
  4. Add datasets with name, color, and values
  5. Toggle legend and grid visibility
  6. Click Save — interactive chart with hover tooltips
