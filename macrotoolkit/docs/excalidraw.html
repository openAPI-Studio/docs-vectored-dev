Wireframe / Whiteboard

Full Excalidraw drawing editor for wireframes, sketches, and whiteboard-style content. Hand-drawn aesthetic, infinite canvas, fully offline.

FULL ONLY

Screenshot placeholder

How to Use

  1. Type /Wireframe in the editor
  2. Full Excalidraw canvas opens in fullscreen
  3. Draw shapes, add text, arrows, freehand sketches
  4. Click Save — exports as SVG on the page
  5. Edit again to modify — all elements preserved

Features

  • Shapes: rectangle, ellipse, diamond, arrow, line
  • Freehand drawing
  • Colors, fill styles, stroke styles
  • Infinite canvas with zoom/pan
  • Hand-drawn sketch aesthetic
  • No external service — fully offline

Limitations

Diagram data stored in macro config (~200KB limit). Very complex wireframes may exceed this. For heavy diagrams, use Draw.io instead (uses Forge Storage).
