Markdown

Render GitHub-flavored Markdown on your Confluence page — tables, code blocks, strikethrough, task lists, and more.

Screenshot placeholder

How to Use

  1. Type /Markdown in the editor
  2. A fullscreen editor opens with text panel (left) and live preview (right)
  3. Write your Markdown content
  4. Click Save — formatted content renders on the page

Supported Syntax

  • Tables
  • Fenced code blocks
  • Task lists
  • Strikethrough
  • Headings & lists
  • Links & images
