Sticky Note

Add colorful sticky notes with a handwritten poster-note aesthetic. Customize colors, fonts, sizes, and attachment styles (tape or pin).

Screenshot placeholder

How to Use

  1. Type /Sticky in the editor
  2. Choose color: 7 presets (yellow, orange, pink, green, blue, purple, white) + custom picker
  3. Choose size: Small, Medium, Large, Full Width
  4. Choose font: Handwritten, Sans-serif, Serif, Monospace
  5. Choose attachment: Tape (with color), Pin, or None
  6. Set layout: alignment, vertical position, line spacing
  7. Write your note and click Save
