Poll / Vote

Create interactive polls with real-time results and voter tracking. Supports single answer, multiple answers, thumbs up/down, and emoji reactions.

Screenshot placeholder

How to Use

  1. Type /Poll in the editor
  2. Choose a poll type: Single Answer, Multiple Answers, Thumbs Up/Down, or Emoji Reactions
  3. Enter your question and options (not needed for thumbs/emoji)
  4. Optionally set alignment and allow vote revocation
  5. Click Save — users can vote on the published page
  6. Click vote counts to see who voted for what

Poll Types

Single Answer

Radio buttons — one choice per user

Multiple Answers

Checkboxes — multiple choices allowed

Thumbs Up/Down

Simple binary toggle buttons

Emoji Reactions

Custom emoji toggle buttons
