Mood

Create a live mood board visualization where team members express their mood. Entries float and grow larger as more people vote, creating a dynamic word cloud.

Screenshot placeholder

How to Use

  1. Type /Mood in the editor
  2. Choose a type: Custom Text (users type their own word, max 20 chars) or Emoji Set (preset emojis)
  3. Optionally add a title
  4. Click Save
  5. On the published page: users submit moods or click existing ones to vote
  6. More votes = bigger text/emoji in the visualization
