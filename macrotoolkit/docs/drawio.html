Draw.io Diagram

Full draw.io diagramming editor embedded in Confluence. Create flowcharts, architecture diagrams, wireframes, and more with draw.io's complete toolset.

FULL ONLY

Screenshot placeholder

How to Use

  1. Type /Draw.io in the editor
  2. The draw.io editor opens in fullscreen
  3. Create your diagram using draw.io's tools
  4. Click Save & Exit — the diagram renders on the page
  5. Edit again to modify — all pages and layers are preserved

Important Notes

External Service Required

This macro uses embed.diagrams.net for both editing and viewing. Must be enabled by an admin in Macro Toolkit Settings (disabled by default).
