Multi-Section Forms Pro

Break long forms into multiple pages with built-in navigation. This feature is available on the Pro tier.

Adding Sections — Stacked View

Sections are edited in a single stacked view: they appear one after another inside the form canvas, so you always see the whole form. Click + Add Section at the bottom of the canvas to append one.

  • Each section has a header with its number, an inline title field, and a live question count.
  • Every section gets its own + Add Question control.
  • Deleting a section that contains questions asks for confirmation first; empty sections delete instantly.

Navigation

While the builder shows sections stacked, respondents see one section per page — they navigate with Next and Back buttons, and the Submit button only appears on the final section.

Per-Section Validation

Validation is enforced per section — users must complete all required fields and pass constraints before advancing to the next section.
