Depotex Admin Guide

Install, license, configure, secure and run Depotex: everything administrators and operators need

This guide is for the people who install and run Depotex: platform and infrastructure engineers, Depotex super admins and organization admins, and security teams. People who publish and download packages need the user guide instead. Pages both need, such as spaces, API tokens, SBOMs and the changelog, are in both guides.

1. From nothing to production

  1. Plan — Choose single server or cluster, size PostgreSQL, Redis and storage, and open the network paths. Plan an installation
  2. Install — On Kubernetes with the Helm chart, or from the container images or the server program (Install Depotex). Behind a reverse proxy, route /api/ws to the server.
  3. License — Read the installation ID and request a license from Vectored (Get a license).
  4. Set up — In the setup wizard, or without the UI from a YAML file.
  5. Configure — The Depotex address, email, directories and single sign-on, storage, rate limits (Settings reference).
  6. Secure — Work through the production checklist, and subscribe to security advisories.
  7. Operate — Backups and test restores, the system check, monitoring, alerts and upgrades.

2. Who administers what

RoleCanTypical person
Super adminEverything: installation settings, license, storage, backups, every space and repository, pluginsPlatform team
Organization adminPeople, groups, roles and policies of their organization; organization-level settingsTeam or department lead
Space Owner / MaintainerA space's repositories, members, upload rules, cleanup and tagsTeam that owns the packages
Operator (no Depotex role)The servers, PostgreSQL, Redis, storage, the reverse proxy and the environmentInfrastructure / SRE

What each role may do comes from its permissions; Users & Directories lists them, and each feature's page names the permission it needs. How access fits together shows how directories, system roles, groups, space roles and repository roles combine, with a worked example.
