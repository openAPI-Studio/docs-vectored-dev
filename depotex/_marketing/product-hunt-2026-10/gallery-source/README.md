# Gallery images: source

`gen.js` draws the eight 1270×760 gallery images (rendered at 2×) and the 240×240 thumbnail with Playwright. Copy the screenshots it names from `depotex/assets/` (plus `mcp-crop.png`, the top 310 px of `plugins-connect-ai-agent.png`) next to it, then run `node gen.js <output-dir>`.
