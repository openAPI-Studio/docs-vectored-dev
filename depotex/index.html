Depotex

Self-hosted artifact repository for every package your teams build and use, on one server or many.

Depotex is a self-hosted artifact repository: one place for the packages, container images, models and files your teams build and depend on. It serves 15 package formats to the tools developers already use, keeps copies of public registries close to your builds, and gives security and platform teams the controls around them: SBOMs and known vulnerabilities, quarantine, a block list, policies and a full audit log. It runs on a single server or as a cluster, with the same features either way.

2. How it's organised

  • Spaces belong to the installation and hold repositories; a repository has one format and one type (hosted, proxy or group) and holds versions of components, each with its files.
  • Every artifact has an address under /repository/<space>/<repository>/…, which is what package managers and CI use; people use the same Depotex in the browser.
  • What someone may do comes from their system role (member, organization admin, super admin) and their role in each space. Tokens and applications never do more than the person behind them.
  • Every major operation is an event: policies can stop it before it happens, and automation, plugins and the audit log see it after.

JavaScript and TypeScript packages for npm, pnpm, Yarn and Bun.

Python packages for pip, uv, Poetry, PDM and Pipenv; publishing with twine, uv, Poetry, Hatch and Flit.

Docker

Container images and OCI artifacts for docker, BuildKit, Helm, ORAS and other OCI tools.

Go

Go modules for the go command: a GOPROXY for go get, go mod download and builds.

Helm

Kubernetes Helm charts for helm repo add, install and pull, published with a PUT or helm cm-push.

NuGet

.NET packages for dotnet, Visual Studio, Rider and nuget.exe: a NuGet v3 source with push, unlist and search.

Cargo (Rust)

Rust crates for cargo: a sparse registry with publish, yank, owners and search, crate docs, and Rust toolchains for rustup.

APT

Debian and Ubuntu packages for apt and apt-get, with signed indexes, published with a PUT or POST.

YUM

RPM packages for dnf and yum, with signed repodata, trusted package keys and several distributions in one repository.

Raw

Any file at any path, for curl, scripts and tools without a package format.

Terraform

Terraform and OpenTofu providers and modules for terraform init: a registry and a provider network mirror.

Hugging Face

Models, datasets and Spaces for huggingface_hub, the hf command, transformers and datasets.

Git LFS

Large files of git repositories hosted anywhere, stored in Depotex: batch API, transfers and file locking.

Composer (PHP)

PHP packages for composer require, install, update, search and audit, uploaded as zip archives.

Browse

Backups

Integrity

Check that every stored file is really in storage and unchanged, hide broken files, and delete them after a while.

Block list
