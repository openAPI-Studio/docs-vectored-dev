2. Initial release

The first release of Depotex: a self-hosted artifact repository that runs on a single server or as a cluster, with the same features either way. Later releases are listed above this one as they ship.

AreaWhat's included
Package formatsMaven, npm, PyPI, Docker and OCI images, Helm, Go, NuGet, Cargo, APT, YUM, Terraform and OpenTofu, Hugging Face, Git LFS, Composer and raw files, each working with its standard client for downloading and publishing.
RepositoriesHosted repositories; proxy repositories that cache Maven Central, npm, PyPI, Docker Hub, internal mirrors or another Depotex; group repositories that combine them behind one address, with a universal address per format in every space. Write policies, upload rules, cleanup policies, storage quotas and uploads from the browser. Deleted repositories can be restored for 7 days. New spaces start with a default storage quota (50 GB, set in Settings → Repositories).
Spaces and accessSpaces that are private, internal or public, with Viewer, Developer, Maintainer and Owner roles for people, groups and service accounts, per-repository access and content selectors.
Browsing and searchThe artifact browser: search across every repository you can see, filters, a tree per repository, and a page per version with install commands, files, checksums, dependencies and security status. Search from the top of every page (Ctrl+K or /) for the spaces, repositories, artifacts, settings, people and groups you can open.
SBOMs and vulnerabilitiesSBOMs in SPDX and CycloneDX, stored with artifacts, uploaded for applications from CI, or made by Depotex from package metadata or a lockfile the package ships, for Maven (with parent POMs), npm, PyPI, Go, Cargo, NuGet and Composer, and read from container images with Syft (Pro); operating system packages checked per distribution release, including those in APT and YUM repositories once their release is set; coverage scores that say how much of each version could be checked (Pro); first-seen dates, "new since upload" and a fix-it checklist with the upgrade command; a Security tab that sums up a version (vulnerabilities, coverage or why there is none, re-check), then cards for each SBOM with its downloads and exports; re-checks that alert instead of quarantining, or quarantine after a grace period; malformed SBOMs listed as unreadable instead of quarantined; completeness scores, each vulnerability explained in place (its weakness by name, the CVSS vector in plain words, the affected versions of every release line and the fix for yours, its description), component search everywhere, vulnerability data from OSV (asked online, or downloaded and matched inside the installation, or uploaded for installations with no internet), scanner plugins whose findings merge with OSV's and count in policies, SBOMs packed inside wheels, NuGet packages and Java archives, re-check and re-inspect on request for a version, a repository or everything, VEX assessments, AI BOMs for models and datasets, and export and sharing.
Supply-chain controlsQuarantine rules and manual holds, the block list, integrity checks of every stored file, and automatic quarantine of unsafe package metadata.
Policies, automation and pluginsPolicies that block, warn about or adjust actions, from templates or your own conditions, with dry runs, exemptions and compliance scans; automation rules that send alerts, webhooks and emails on events; signed plugins, including MCP servers for AI applications and an API explorer.
Users and sign-inDirectories: Local, LDAP, Active Directory, Microsoft Entra ID, Google Workspace and SCIM; single sign-on with OpenID Connect and SAML; your profile settings (avatar, theme and language: English or German, notifications, password, sessions, tokens and connected apps); invitations and password resets by email, profile pictures in every list of people (profiles:view), sessions and timeouts, CAPTCHA, lockout after failed attempts, anonymous access, and GDPR data export and anonymization.
Applications and tokensOAuth applications with consent, device sign-in for command-line tools, service accounts and workload identity for CI; API tokens with permissions, templates to start from, expiry, IP allowlists and rotation; rate limits, overrides and download quotas.
NotificationsIn-app alerts with the bell, a notifications page and preferences; email through SMTP providers or the Amazon SES API with an IAM role; banners for announcements, with an optional title.
AdministrationThe dashboard, the system check and cluster health, scheduled jobs, log levels, log files and exports, the audit log, profiling, Prometheus metrics, branding per theme and your own help links.
Backups and recoveryBackups on a schedule or on demand, encrypted, kept on a separate target, checked and test-restored; restore into a new installation from the setup wizard; recovery mode when an installed server can't start.
InstallationA setup wizard or an unattended setup file; container images and a Helm chart; a single server or a cluster with Redis as one server, Sentinel or Redis Cluster; storage on a local disk, S3 (with IAM roles), MinIO or Azure Blob.
