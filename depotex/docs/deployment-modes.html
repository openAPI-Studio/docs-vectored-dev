Single Node & Cluster

Run Depotex on one node or many with the same features

Every Depotex feature works the same on one node or many. What changes is how the nodes coordinate. On Kubernetes, the Helm chart runs the server as a StatefulSet and scales it with backend.replicas: see Docker & Kubernetes.

1. Redis

Give Redis as a URL in the setup wizard, the unattended setup file (cache.redis_url) or the recovery page. Depotex supports three kinds:

KindURL
One serverredis://:password@redis.internal:6379/0, or rediss:// for TLS
Sentinel groupredis+sentinel://:password@s1:26379?master_name=mymaster&addr=s2:26379&addr=s3:26379: Depotex follows the primary when Sentinel fails over
Redis Clusterredis+cluster://:password@n1:6379?addr=n2:6379&addr=n3:6379: every shard is used
  • Each kind takes TLS (rediss, rediss+sentinel, rediss+cluster), a private certificate authority (ca_file=/path/ca.pem) and Redis ACL users (user:password@).
  • Redis coordinates; PostgreSQL keeps the records. If Redis becomes unavailable, Depotex keeps working: each server counts rate limits on its own, sign-in keeps working, and changes reach other servers within 30 seconds instead of at once. It logs one warning when Redis goes and one message when it returns.
  • A failover can lose the last few writes to Redis; results stay correct because PostgreSQL holds the records.

2. Clustering

Nodes register themselves, send heartbeats, and elect a leader. Settings → Clustering lists every node in a table: status (the leader has a crown), health, name and machine ID, version, CPU, memory, uptime and last heartbeat. Cluster health above the table sums up every server's latest self-check, with View server for each thing that needs attention. Select a node to open its identity, resources and recent events below its row, and rename it with the pencil (Pro). A node that stops responding gets a red notice above the table saying how many heartbeats it missed, with View node. How clustering works and the environment variables that tune it are explained below the table.

StatusMeaning
activeRunning.
drainingShutting down: finishing its work before it stops.
