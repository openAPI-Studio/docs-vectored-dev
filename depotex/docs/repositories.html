Repositories

Create and manage artifact repositories

A repository holds artifacts of one format and belongs to a space. Its address is /repository/<space>/<repository>/, so the name only has to be unique within its space. There are three types: hosted (stores what is published to it), proxy (fetches from an upstream such as Maven Central and keeps a copy; Pro license or higher) and group (combines repositories of the format behind one address; see Repository groups).

1. Create a repository

  1. Open the space — Choose Spaces in the sidebar, open the space and its Repositories tab.
  2. Select New repository — You need the space's Maintainer or Owner role, or to be a super admin.
  3. Enter a name — 2–64 characters: lowercase letters, digits, dots, underscores or hyphens, starting with a letter or digit. It is part of every artifact address and can't be changed later. Format names (npm, maven, …) are reserved: /repository/<space>/<format>/ is the space's universal address for that format.
  4. Pick a format and a type — Only the formats the space allows are offered (see Supported formats); the format can't be changed later. A proxy repository also needs an upstream from the space's list; a group needs its members, in the order they're asked, and the member uploads go to, and can become the space's universal address for the format.
  5. Add a description — optional.
  6. Select Create repository — It appears in the list and can be used at once.

A repository opens on Browse, with its address, setup instructions for its package manager and its contents; Versions, Settings and Access are beside it. See Spaces → Repositories for settings, access, upload rules and cleanup.

2. Every repository

Repositories in the sidebar (super admins) lists every repository of the installation, grouped by space: its format, type, whether it can be published to and overwritten, and when it last changed. Filter by format, type, space or name; Browse opens a repository in the artifact browser, Open space opens its space.

3. Delete a repository

Choose the bin next to a repository, in its space or in the list above, and confirm. The repository and everything in it are deleted; this can't be undone. A repository that belongs to a group is taken out of it; if it was where the group's uploads went, the group has no upload target until you choose one.
