What Kee can do: the tool reference

The tools Ask Kee, agents and outside AI apps use to read and change the Wiki, what each one does, its class and the access it needs

Kee doesn't read the whole Wiki at once. To answer, the model asks for what it needs through tools, one at a time: search for pages, read a page, propose a change. The same list of tools serves Ask Kee, agents and outside AI apps. Each tool runs as the person who asked, with the same access checks as the Wiki's own screens, so it can never read or change more than that person could.

1. How the tools work

  • Each tool returns at most what the person could see in the browser: a restricted or locked page they are not on doesn't exist for the tool.
  • Nothing of a space whose admins turned Kee off is ever returned or changed, whoever asks, also through outside AI apps.
  • A page's id is its space key and number, such as OPS/42; answers link to /spaces/{key}/pages/{id}.
  • A long page comes back as its outline and first section, with a note; the model can then ask for the sections it needs. Images, mentions, macros and HTML blocks are described by their captions or titles, never sent as content. get_page names up to 10 of a page's attached files.
  • An answer's sources are only pages a tool returned while answering that question.

2. Classes: who does what

Every tool has one class. The class decides how it runs:

A change or admin tool takes from the person's usual budgets for publishing, comments and labels, in Kee's Apply and through an app alike; when one is used up the tool says how long to wait. Tools that remove something are marked destructive, so AI apps ask before they run them.

3. Groups of tools

Tools come in groups (toolsets). Ask Kee loads Core, Product docs and Tool search, plus the groups the screen you ask on needs (a page's attachments, a history's versions). Outside AI apps get the same three in every connection, plus the groups a person chooses for the connection. Everything else is found by the model when it needs it, through find_tools and call_tool, which apply the same checks. The Wiki administration group is for outside AI apps only.
