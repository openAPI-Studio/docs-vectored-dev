Frequently asked questions

Answers to the questions administrators ask most

1. Licensing

  • How do I get a licence? Read the installation ID (setup wizard, Settings → Application → Licensing, or ./wiki-server --machine-id) and send it through vectored.dev/#contact or to support@vectored.dev. See Licensing.
  • Why is there no Analytics menu? Page analytics need a Pro licence.
  • What happens when the licence expires? Any grace period first, with banners; then only sign-in, health checks and the licence page answer, until a new licence is applied. Nothing is deleted.
  • Does the Wiki call home? No. It doesn't need internet access to check its licence.

2. Installation

  • Do I need Redis? Not for a single server. A cluster needs it. See Single server & cluster.
  • Which PostgreSQL? 15 or later; managed services work.
  • People can't edit pages together; the editor says it can't connect. Route /api/ws to the server with WebSocket upgrades allowed. See Install the Wiki.
  • Video uploads fail with 413. The proxy in front of the Wiki refuses large bodies: let it take 201 MiB (nginx: client_max_body_size 201m).
  • Can I set it up with no browser? Yes: Set up without the UI.

3. Content

  • How do we move from Confluence? Export each space (XML, full export) and import it into a Wiki space: Imports. Importing again later updates what the first import made.
  • Who can create spaces? Super admins. They then hand a space to its team with the Admin role.
  • How do we publish a space to the internet? Turn on anonymous access, make the space public, and choose what search engines may index.

4. Access

  • I'm locked out: single sign-on is down. Start one server with SSO_ENFORCEMENT_OVERRIDE=true, sign in with a password as a super admin, fix the provider, then remove the variable.
  • An account is locked after failed sign-ins. It unlocks after AUTH_LOCKOUT_DURATION (15 minutes), or an administrator unlocks it in Settings → Access management → Users.
  • Someone's calendar address leaked. They make a new one on the Calendar page; ending their sessions also stops it. See Calendar feeds.
  • Why does everyone seem to come from the same address? The web app ignores forwarding headers unless FRONTEND_BEHIND_PROXY=true is set on it, and the server trusts them only from the proxies in TRUSTED_PROXIES and removes them otherwise. Set both; the system check's Forwarded headers line names an address that was refused. See Install the Wiki.

5. Data

  • What's in a backup? See Backups.
  • I lost CONFIG_ENCRYPTION_KEY. Stored credentials and backups made with it can't be read; there is no recovery. Keep the key in a secret store and with your backup records.
  • How long are page views kept? Raw views 90 days, daily totals as long as the page. See Analytics.
